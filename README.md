---

## 🚀 Visão Geral

Este repositório é o **Hub Central de Portfólio e Catálogo de Soluções do StudioIA360**, combinando:
1. **Aplicação Web Interativa** em tema escuro, minimalista e performática, permitindo busca em tempo real, filtragem por 14 verticais de mercado e inspeção detalhada de cada projeto.
2. **Issue Factory Centralizada**: 40 GitHub Issues registradas e rastreáveis contendo especificações técnicas completas, distinção entre fatos e hipóteses, e prompts prontos para execução futura de cada repositório dedicado.
3. **Padrão Firebase**: Preparado para deploy contínuo via Firebase Hosting (`firebase.json` e `.firebaserc`).

---

## 🎯 Padrões Adotados

- **Firebase Hosting:** Arquitetura estática veloz e segura configurada para entrega global.
- **Idioma PT-BR:** Interface, metadados e documentação primária totalmente em português brasileiro, com especificações para entregáveis internacionais em inglês natural nos prompts de execução.
- **Estética Clean & Moderna:** Paleta dark refinada (`#07090e`), componentes em glassmorphism translúcido, gradientes dinâmicos sutis (ciano, índigo e esmeralda) e tipografia moderna (Google Fonts Outfit + Inter).
- **Interatividade Total:** Barra de busca instantânea com atalhos de teclado (`/` e `Esc`), seletor de chips por verticais de negócio, ordenação dinâmica, modal completo de inspeção e cópia rápida de prompts com feedback visual.

## 🛠️ Execução e Teste Local

Para rodar a aplicação web localmente:

```bash
# Com qualquer servidor HTTP simples:
npx serve public
# ou com Python:
python3 -m http.server 8080 --directory public
```

Para deploy no Firebase Hosting:
```bash
firebase deploy --only hosting
```

## 📌 Metodologia de Execução Futura

Cada Issue contém o prompt estruturado e individualizado para sua respectiva fase de implantação técnica:
- Criação de repositório dedicado com slug técnico padronizado.
- Redação de copy em inglês internacional pronto para sites globais.
- Criação do prompt para geração da hero image.
- `README.md` detalhado e rastreabilidade com a Issue de origem.
- Respeito ético, LGPD e rotulação rigorosa de metas como estimativas ilustrativas a validar.
